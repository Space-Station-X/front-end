BIENVENIDOS A POLVOS AZULES

Encuentra tus videojuegos favoritos en un solo lugar!...

Somos un equipo de tres desarrolladores trabajando en la creación de una página web para la tienda de videojuegos Polvos Azules. Nuestro objetivo es proporcionar una plataforma moderna y segura donde los clientes puedan explorar y comprar videojuegos de manera rápida y sencilla.

Para lograr esto, estamos utilizando Spring Boot en el backend, implementando Spring Security con autenticación basada en tokens para garantizar la seguridad de los usuarios. En el frontend, usamos Angular para ofrecer una experiencia fluida e interactiva.

Este proyecto busca no solo digitalizar la tienda, sino también mejorar la experiencia del usuario y facilitar la gestión de productos y ventas en línea.
